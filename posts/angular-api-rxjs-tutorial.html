API hívások és RxJS: A reaktív adatáramlás

Publikálva: 2026. június 5.

A modern webalkalmazások szíve az adatok lekérése a szerverről. Az Angular ehhez a HttpClient modult és az RxJS könyvtárat használja, ami az aszinkron adatáramlás mestere.

1. HttpClient: A kapocs a szerverhez

Az Angular HttpClient eszköze Observable objektumokat ad vissza. Ez azt jelenti, hogy feliratkozhatunk az adatokra, és kezelhetjük a hibákat vagy az átalakításokat.

this.http.get<User[]>('/api/users').subscribe(users => {
  this.users = users;
});

2. Miért RxJS?

Az RxJS operátorok (mint a map, filter, switchMap) lehetővé teszik, hogy komplex adatfolyamokat kezeljünk egyszerűen. Például egy keresőnél elkerülhetjük a felesleges API hívásokat a debounceTime operátorral.

3. Újdonság: httpResource (v22+)

Az Angular 22 bevezette a httpResource-t, ami ötvözi az API hívásokat a Signalokkal. Nincs többé szükség kézi feliratkozásra (`subscribe`), az adat automatikusan Signal lesz!

users = httpResource<User[]>('/api/users');
// A template-ben: users.value()

Már majdnem a végére értél az útvonalnak! A következő lépés az alkalmazásod élesítése a nagyvilágnak. 🚀
