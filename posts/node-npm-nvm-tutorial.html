Node.js Ökoszisztéma Kalauz: nvm, Node és npm profiknak

Publikálva: 2026. június 4.

Az Angular fejlesztés alapköve nem maga a keretrendszer, hanem az a futtatókörnyezet és csomagkezelő rendszer, amin nyugszik. Ez az útmutató segít rendet tenni a verziók és eszközök között.

1. Az Alapok: Miért kell nekünk az nvm?

Soha ne telepíts Node.js-t közvetlenül a weboldalról letöltött installerrel! A probléma: Különböző projektjeid különböző Node verziókat igényelhetnek (pl. egy régi v16-os legacy projekt és egy új v22-es Angular projekt). A megoldás: nvm (Node Version Manager). Ez lehetővé teszi, hogy több Node verziót tarts a gépeden és egyetlen paranccsal válts közöttük.

Telepítés (Linux/macOS):

curl -o- https://raw.githubusercontent.com/nvm-sh/nvm/v0.40.1/install.sh | bash

(Windowsra az nvm-windows használata javasolt.)

2. Node.js Kezelés: LTS vs. Current

A Node.js-nél két fő ágat különböztetünk meg:

  • LTS (Long Term Support): Stabil, produkciós környezetbe szánt verziók (pl. v20, v22, v24). Angular fejlesztéshez mindig ezt válaszd!
  • Current: A legfrissebb funkciókat tartalmazza, de kevésbé stabil.

3. npm: A Csomagkezelő Művészete

Az npm (Node Package Manager) nem csak könyvtárak letöltésére való. A profik tudják, hogyan tartsák tisztán a node_modules mappát.

Telepítési típusok:

  • npm install <név>: Csak az adott projektben futáshoz kell (pl. RxJS).
  • npm install -D <név>: Csak fejlesztéshez kell (pl. TypeScript, ESLint).
  • npm install -g <név>: Globális eszközök (pl. @angular/cli).

4. Angular Specifikus Verziókezelés

Az Angular CLI rendkívül érzékeny a Node verzióra. Az Angular 22 például legalább v22.22.3 vagy v24.15.0+ verziót igényel.

Pro Tipp: Az .nvmrc fájl

Helyezz el egy .nvmrc fájlt a projekt gyökerébe, amibe csak a verziószámot írod (pl. 24.16.0). Ezután a projektbe lépve elég egy nvm use parancs, és az nvm automatikusan a megfelelő verzióra vált.

5. Frissítési Workflow

Ha új Node verzióra váltasz, ne telepítsd újra manuálisan a globális csomagokat! Használd a következő parancsot:

nvm install 24 --reinstall-packages-from=22

6. Trükkök és Hibaelhárítás

"Tele van a lemezem!"

Használd az npkill eszközt a felesleges mappák gyors törléséhez:

npx npkill

Hiba van a globális csomagban!

Ha az ng parancs furcsa hibákat dob egy frissítés után:

npm cache clean --force
npm install -g @angular/cli@latest

Legyen a kódotok tiszta, a buildetek pedig gyors! 🚀
